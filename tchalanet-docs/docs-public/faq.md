# FAQ testeurs

!!! warning "Environnement de validation"
    **Environnement : STAGING**  
    **Données : tests uniquement**  
    Aucun ticket ou montant n'a de valeur réelle.  
    **Version testée : à renseigner avant livraison**  
    **Dernière mise à jour : 2026-07-23**

## Est-ce que les tickets de staging ont une valeur réelle ?

Non. Les tickets, montants, reçus et rapports de staging servent uniquement à la
validation.

## Que faire si mon PIN ne fonctionne pas ?

Vérifiez le terminal utilisé, l'heure du test et le message exact. Signalez le
problème avec le format de la page [Signaler un problème](validation/signaler-un-probleme.md).

## Que faire si le terminal est bloqué ?

Notez le code terminal, le rôle utilisé, l'heure et la capture du message.
N'essayez pas de contourner avec un autre compte sans consigne.

## Que faire si un tirage est fermé ?

Notez le tirage, l'heure et la capture. Cela peut être normal selon l'horaire,
mais le statut doit être compréhensible.

## Que faire si l'impression ne marche pas ?

Notez l'appareil utilisé, l'imprimante ou méthode de reçu, le code ticket et une
capture/photo de l'erreur si disponible.

## Quelle différence entre staging et production ?

Staging sert à tester avant livraison. Production contient des données réelles
et ne doit pas être utilisée pour ces scénarios sans consigne explicite.
