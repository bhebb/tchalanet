Le propriétaire supervise l'entreprise ou le santral : vendeurs, terminaux POS,
limites, commissions et activité. Il regarde la santé opérationnelle et la
capacité de vente, pas le détail technique.

Pendant la validation, le propriétaire doit confirmer que les informations
importantes pour piloter l'activité sont visibles et compréhensibles.

## Ce que le propriétaire valide

- Informations d'entreprise ou santral.
- Vendeurs et terminaux POS.
- Limites et commissions visibles.
- Activité commerciale lisible.
- Accès aux rapports nécessaires.

## Parcours conseillé

1. Se connecter comme propriétaire ou profil équivalent.
2. Vérifier les informations entreprise/santral.
3. Vérifier la liste des terminaux POS.
4. Vérifier les vendeurs associés.
5. Vérifier les limites configurées.
6. Vérifier les commissions ou paramètres commerciaux disponibles.
7. Consulter l'activité ou les rapports.

## Résultats attendus

| Zone | Ce que vous devez confirmer |
|---|---|
| Entreprise / santral | Le nom, l'adresse et les informations utiles sont corrects ou modifiables si autorisé |
| Terminaux POS | Chaque terminal a un nom/code et un statut compréhensible |
| Vendeurs | Les vendeurs attendus sont présents ou l'état vide est clair |
| Limites | Les limites de vente sont lisibles et associées au bon périmètre |
| Commissions | Les règles commerciales disponibles sont compréhensibles |
| Activité | Les ventes de test se reflètent dans les rapports ou tableaux |

## Actions permises

| Action | Attendu |
|---|---|
| Consulter entreprise/santral | Informations claires et modifiables si autorisé |
| Consulter terminaux | Statut terminal lisible |
| Consulter vendeurs | Association vendeur/terminal compréhensible |
| Consulter limites | Limites visibles sans vocabulaire technique |
| Consulter activité | Données cohérentes avec les ventes de test |

## Points d'attention

- Le mot "terminal POS" peut représenter la machine ou le point de vente.
- Les montants de staging ne sont jamais réels.
- Si un vendeur ou terminal manque, noter le tenant/santral et l'heure.

## Quand signaler

Ouvrez un signalement si :

- un terminal ou vendeur attendu n'apparaît pas ;
- un statut est contradictoire entre deux pages ;
- une limite ou commission semble appliquée au mauvais périmètre ;
- l'activité ne reflète pas les ventes de test après quelques minutes.
