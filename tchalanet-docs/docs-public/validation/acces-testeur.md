# Fiche d'accès testeur

Utilisez cette fiche pour préparer chaque testeur avant la séance de validation.

## Informations à fournir

| Élément | Valeur |
|---|---|
| Environnement | STAGING |
| Version documentation | POC 2026-07-23 |
| Version portail admin | À renseigner avant séance |
| Version mobile POS | À renseigner avant séance |
| URL documentation | `https://docs.tchalanet.com` |
| URL portail admin | `https://test.tchalanet.com` |
| Installation mobile POS | Lien Firebase App Distribution fourni au testeur |
| Santral de test | À renseigner |
| Provider POC par défaut | NY, FL |
| Contact support | À renseigner |

## Comptes et appareils

| Besoin | À renseigner |
|---|---|
| Compte administrateur | Email ou identifiant |
| Compte propriétaire | Email ou identifiant |
| Compte super administrateur | Email ou identifiant, si nécessaire |
| Terminal POS | Code terminal |
| PIN temporaire | Remis séparément |
| Appareil mobile | Modèle et OS |
| Imprimante ou méthode reçu | Bluetooth, partage, PDF ou autre |

## Rappel au testeur

- Ne pas tester en production sans consigne explicite.
- Ne pas partager de PIN dans les captures.
- Noter l'heure de chaque blocage.
- Garder le code ticket pour toute vente de test.
- Utiliser la page [Signaler un problème](signaler-un-probleme.md) dès qu'un
  résultat attendu ne correspond pas.
