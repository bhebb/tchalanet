# Formulaire de résultat

Ce formulaire sert à documenter une saisie, une vérification ou une correction
de résultat pendant la POC.

```text
Action :
☐ Vérification
☐ Saisie manuelle
☐ Confirmation
☐ Correction / override

Santral :
Provider :
Tirage :
Date du tirage :
Heure du tirage :
Fuseau affiché :

Source consultée :
Heure de consultation :

Lot 1 :
Lot 2 :
Lot 3 :
Lot 4 :

Statut avant action :
Statut après action :

Qui a effectué l'action :
Raison ou commentaire :

Évidence jointe :
☐ Capture source officielle
☐ Capture Tchalanet avant action
☐ Capture Tchalanet après action
☐ Trace ou message d'erreur
```

## Règles

- Ne confirmez pas un résultat incomplet.
- Ne mélangez pas les valeurs Pick 3 et Pick 4 si la source les publie séparément.
- Notez explicitement les lots absents.
- Après correction, vérifiez que l'audit affiche qui a changé quoi et quand.
